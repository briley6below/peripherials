Comments

The ASUS ROG Strix Scope II 96 Wireless is a compact (96%) keyboard that continues ASUS' ROG Strix Scope lineup. You can connect this keyboard wirelessly with the included ROG Omni USB receiver or via Bluetooth with up to three devices simultaneously. There's also a programmable multi-function button and scroll wheel that you can customize along with the keyboard's RGB backlighting and other settings using the companion software. You can buy this keyboard with either linear or clicky ROG NX mechanical switch options, and it has a hot-swappable PCB, allowing you to change these stock switches for others of your choice if you prefer. Additionally, the keycaps are made of durable PBT plastic, and sound-dampening switch pads and silicone foam inside the case help keep the typing volume to a minimum.

Our Verdict
N/AGaming 

The ASUS ROG Strix Scope II 96 is an excellent keyboard for gaming. It has impressive overall build quality and remarkably low latency performance, making it well-suited for playing games in any genre and at any competitive level. It also has full RGB backlighting that you can customize along with other keyboard settings directly on the keyboard using hotkeys or using the customization software.

Differences Between Sizes And Variants

The ASUS ROG Strix Scope II 96 Wireless is available in a black or white colorway and with ROG NX mechanical switch options. We bought and tested the Black color option with linear ROG NX Snow switches. You can see the label of our unit.

The wider ASUS ROG Strix Scope II lineup offers several other size variants of this keyboard. We expect our tests to apply very closely to these models, and we've included a table comparing these models below.

An additional keyboard within the Strix Scope II lineup called the Strix Scope II RX uses ROG RX optical switches rather than ROG NX mechanical switches. We expect the majority of our tests to also apply to this keyboard. However, we expect it to have different performance characteristics, so we expect the Single-Key Latency, Multi-Key Latency, Data Transmission, and Chord Split tests not to apply.

Popular Keyboard Comparisons

The ASUS ROG Strix Scope II 96 Wireless is a compact (96%) model in ASUS' wider lineup of Strix Scope gaming keyboards. This is the first wireless model and the first 96%-sized model in the series. This compact form factor provides all of the keys of a standard full-size keyboard but with only minimal space between key clusters, so the entire keyboard takes up less space on your desk. Along with other recent models in this lineup, this keyboard has taken a nod from recent developments in the custom keyboard market with the addition of sound-dampening materials, doubleshot PBT keycaps, and a hot-swappable PCB. It's also available in either clicky or linear switch options that come pre-lubed from the factory.

Ultimately, this keyboard is a great option if you're interested in a hot-swappable wireless gaming keyboard that has a slightly smaller footprint than full-size options like the ASUS ROG Strix Flare II Animate but still offers many more keys than a smaller compact model, like the ASUS ROG Azoth.

For more options, see our recommendations for the best mechanical keyboards, the best gaming keyboards, and the best wireless keyboards.

1. Multi-Key Latency and Connection Type
Funny you should mention this—we have started to reconsider how we test multi-key latency for wireless capable keyboards. The reason why we’ve only evaluated the Receiver connection is that we generally try to prioritize testing the configuration we expect most people will use in most cases. 
But we recognize this doesn’t always make sense as many people may switch to a wired connection when they’re most concerned about latency performance. While this isn’t yet an official part of our methodology, we’ve begun testing both wired and wireless connections in some cases. As a matter of fact, if you’re interested in a bit more context, we just performed retests on another gaming keyboard, the Corsair K65 PLUS Wireless. Our findings there might be able to provide some more insights for you here. Originally, we only tested that keyboard’s wireless Multi-Key Latency performance but decided to do some additional testing over a wired connection as well. We found both the wired Key Press and Key Release results to be ~3 ms faster, which is about what we expected. Also of note, that keyboard suffers from very high release latency for the multi-key latency scenario as well, and it was similarly high regardless of connection type. We expect the ASUS ROG Strix Scope II 96 Wireless to behave similarly.
The short answer: if you’re using a wired connection, we expect slightly better multi-key latency performance (within a few milliseconds of difference), but the overall performance profile will likely be similar. 
2. Key Release Latency and Compounding
As for whether key release latency compounds when multiple keys are released simultaneously, that’s a really interesting question! In short, we haven’t tested this so we can’t say for certain.
But my personal expectation would be yes. With the high release latency of this keyboard in multi-keypress scenarios, I would expect it to compound when playing a rhythm game with triggers on multiple simultaneous releases.
I’ll pass this question on to both our testing and test development teams. So we may be able to investigate this and provide a more definitive answer in the future.
I hope this was helpful! Please don’t hesitate to reach out with more questions—they’re invaluable in helping us refine and improve our testing processes over time.

Why do a lot of led keyboards have the secondary symbols on the number keys not shine through and just etched on? Surely this is a big oversight, The 96 is a good keyboard, but you can’t guarantee which you will get, it seems, with all the legends on the ABS version transparent but not so for the PBT version.
This is a rather big issue if you want to type with the light off, and something you would naturally want to do if you buy an RGB keyboard. If you look on the PBT version, you have some legends such as the {[ key that are double etched, so what is the issue? Is it cost?

Hey ooey,

We can only speculate why manufacturers are inconsistent about providing shine-through legends for the secondary hotkey symbols, but we suspect you’ve hit the nail on the head, and much of the decision likely comes down to cost for the added complexity. That said, there may be some additional reasons to consider as well.

From what we’ve seen, ABS plastic keycaps appear easier for manufacturers to work with when adding detailed shine-through legends. But we’ve increasingly seen them move more towards offering PBT keycap sets as many people prefer the texture and added durability.

Also worth considering is that LEDs are either North or South-facing. Most gaming keyboards, like the ASUS ROG Strix Scope II 96 Wireless, have North-facing LEDs. These provide great illumination for shine-through legends on the top edge of the keycap. However, there’s only limited space on a keycap, so most manufacturers will set secondary legends on the bottom edge of the keycap. Even if these legends were shine-through, they likely won’t get adequate backlight clarity due to the North-facing LED position—especially if the keycaps and switch housings are dark-colored as they don’t reflect as much light.

It might not provide much consolation at the moment, but the keyboard space continues to evolve rapidly. While consistent shine-through secondary legends are still rare on current-generation boards, they may become more common in the future.

Hopefully, those few insights were helpful. Thanks for reaching out!
